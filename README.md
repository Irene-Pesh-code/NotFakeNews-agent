# Агент поиска первоисточника новости

Пользователь пересылает Telegram-боту пост, ссылку или текст новости. Агент выделяет
цитаты, ищет более ранние публикации, идёт по ссылкам «как сообщает…» назад и проверяет
кодом, что цитата есть в тексте каждой найденной страницы.

**Главный принцип:** модель только принимает решения (что искать, что открыть, когда
остановиться). Все факты — тексты, даты, наличие цитат, ссылки, выбор первоисточника
по датам и уровень уверенности — определяет код.

## Установка
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN, LLM_API_KEY, TAVILY_API_KEY
```

## Проверка по шагам
```bash
pytest                                              # тесты
python -m scripts.try_tools llm                     # модель отвечает?
python -m scripts.try_tools search "НДС 2027"       # поиск работает?
python -m scripts.try_tools page https://...        # текст, дата, атрибуции страницы
python -m scripts.try_tools run "текст или ссылка"  # полный прогон агента без Telegram
python -m bot.main                                  # запуск бота
```
Граф каждой проверки сохраняется в `data/graphs/*.json` (для будущей визуализации).

## Структура
- `bot/` — Telegram-бот: приём сообщений, прогресс, оформление ответа
- `core/ingest.py` — разбор входа: пересланный пост / ссылка / текст
- `core/fetch.py` — загрузка страниц, текст, дата, ссылки
- `core/quotes.py` — проверка цитаты в тексте страницы
- `core/attributions.py` — поиск «как сообщает…», «по данным…» и ссылок
- `core/search.py` — веб-поиск (Tavily)
- `core/llm.py`, `core/prompts.py` — модель и инструкции для неё
- `core/agent.py` — цикл агента, граф, правила выбора первоисточника и уверенности
- `core/factory.py`, `core/config.py` — настройки и сборка

## Лимиты (core/agent.py, класс Limits)
16 шагов модели, 6 поисковых запросов, 25 страниц, глубина цепочки 6, ~220 секунд.
